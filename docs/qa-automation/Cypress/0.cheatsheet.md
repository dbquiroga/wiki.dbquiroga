### JavaScript

#### Métodos de uso frecuente

- **Math.random()**: devuelve un número entre 0 y 1
- **Math.floor()**: redondea hacia abajo — evita decimales
- **Math.ceil()**: redondea hacia arriba — evita decimales
- **forEach()**: itera sobre los elementos de un array

```js title="Generar un número random entre 1 y 1000"
const numeroRandom = Math.ceil(Math.random() * 1000)
```

### Tip de la vida

#### Clipboard
Se puede acceder al historial de lo que copiamos (hasta las últimas 20 cosas), lo que facilita mucho el trabajo.

- **Windows**: `Win + V`
- **Linux**: instalar **clipit** — el comando para abrir el historial es `Ctrl + Alt + H`
