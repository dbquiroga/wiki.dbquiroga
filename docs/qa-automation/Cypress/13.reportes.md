Lo normal es tener nuestro repositorio en una plataforma, ej: GitLab, GitHub, Jenkins u otra de integración continua o entrega continua, así se ejecuta automáticamente — por ejemplo todos los días o en una regresión.

De esta manera tendremos reportes automáticamente luego de estas ejecuciones automatizadas.

## Reportes de Cypress
Nos sirve como reporte interno para los QA.
Ejecutando desde la consola el siguiente comando, tendremos un reporte de todos los tests disponibles.
```jsx
npx cypress run
```

Para correr un solo test:
```jsx
npx cypress run --spec 'cypress/e2e/hooks.cy.js'
```
:::note
Poner bien la ruta del test
:::

#### Videos
Realiza un video por cada archivo ejecutado, más allá de si pasan o no.

#### Fotos
Las fotos únicamente se generan si el test falla.

#### Screenshots
Podemos realizar screenshots en momentos que nosotros necesitemos.
```jsx
cy.screenshot('fullPage')
```

También podemos sacar una foto a un elemento particular:
```jsx
cy.get('#id').screenshot()
```
Las screenshots no se eliminan, se guardan todas.
Pero podemos asignarle un nombre a la foto en particular:
```jsx
cy.get('#id').screenshot('modulos')
```
De esta manera la foto se guardará con el nombre "modulos".

## Reportes externos
Para presentar reportes externos se usa Allure o Mochawesome. Cypress sugiere utilizar Mochawesome.
