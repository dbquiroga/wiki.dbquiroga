title: Instalar Xpath Plugin
---

Para usar selectores con xpath, es necesario **instalar un plugin**. Es un plugin oficial mantenido por Cypress y su instalación es bastante estándar.

## Paso 1: Instalar cypress-xpath

~~~
npm install cypress-xpath --save-dev
~~~

:::note
Chequear que en package.json se encuentre:
```jsx
"cypress-xpath": "^2.0.1"
```
:::

## Paso 2: Agregar plugin a index.js

```jsx title="/support/e2e.js"
// Import commands.js using ES2015 syntax:
import './commands'
require('cypress-xpath');
```

Sin agregar esto, el plugin no se registrará y obtendrás el error `cy.xpath is not a function`

## Paso 3: Usarlo

Funcionará agregando el comando `.xpath()`, el cual funciona de manera similar al comando `.get()`. Retorna un elemento HTML.

```jsx
cy.xpath("//input[@id='user']").type('Day')
```
