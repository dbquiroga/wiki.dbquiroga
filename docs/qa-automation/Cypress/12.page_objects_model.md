title: Page Object Model
---

El Page Object Model (POM) es un patrón de diseño que centraliza los selectores y métodos de cada página en su propia clase. Esto evita repetir código en los tests y facilita el mantenimiento: si cambia un selector, se actualiza en un solo lugar.

#### Beneficios
- Evita código duplicado
- Más fácil de mantener
- Código más legible y reutilizable
- Nombres de métodos descriptivos del comportamiento

Se puede implementar con clases o constantes. Lo más habitual es una clase por página (especialmente en Selenium, pero aplica igual en Cypress).

:::note
Por convención, las clases empiezan con mayúscula.
:::

```jsx title="Ejemplo: clase LoginPage"
export class LoginPage {
    escribirUsuario(usuario) {
        cy.get('#user').type(usuario)
    }

    escribirPassword(password) {
        cy.get('#password').type(password, { log: false })
    }

    clickLogin() {
        cy.get('[data-cy="btn-login"]').click()
    }
}
```

```jsx title="Uso en el test"
import { LoginPage } from '../pages/LoginPage'

const login = new LoginPage()

it('debería iniciar sesión correctamente', () => {
    login.escribirUsuario('day@ejemplo.com')
    login.escribirPassword('mi-password')
    login.clickLogin()
})
```
