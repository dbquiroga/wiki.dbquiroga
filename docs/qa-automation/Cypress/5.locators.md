## CSS Selectors

### Elementos HTML

La mejor manera de elegir un elemento es ir por algo único y estable, preferentemente el `id`.

Cypress permite encontrar elementos por `tagName` (la etiqueta HTML, ej: `button`), o por atributos para agregar mayor especificidad.

### Buscar por atributo

Se usan corchetes `[]` para filtrar por atributo:

```js title="Búsqueda por atributo y valor"
cy.get('[name="user"]')
cy.get('[cy-data="login-btn"]')
```

### IDs

Con `id` se puede usar directamente el `#`, equivalente a `[id="user"]`:

```js
cy.get('#user')
cy.get('input#user')  // input cuyo id sea "user"
```

:::note
Si se usan comillas simples afuera, adentro se usan comillas dobles, y viceversa.
:::

### Clases

Las clases se representan con un punto `.`:

```js
cy.get('.password')
```

:::note
Verificar siempre el selector en el inspector del browser antes de usarlo en el test — asegurarse de que exista y sea único.
:::

### Prioridad de selectores

Los primeros 4 son atributos creados específicamente para testing (los más estables):

- `data-cy`
- `data-test`
- `data-testid`
- `data-qa`

Los más frecuentes en apps reales:

- `id`
- `class`
- `tag`
- `attributes`
- `nth-child`

:::note
Con CSS Selectors **no** se puede navegar hacia el elemento padre (de hijo a padre). Solo se puede ir hacia abajo (de padre a hijo). Para subir en el árbol se usan los métodos de Cypress.
:::

### Métodos de Cypress para traversal

- `.find()`: encuentra elementos descendientes
- `.contains()`: encuentra por texto visible (se puede especificar el tag, ej: `cy.contains('p', 'Confirmar')`)
- `.children()`: hijos directos
- `.parent()`: elemento padre
- `.siblings()`: elementos hermanos
- `.first()` / `.last()`: primero o último de una lista
- `.eq(n)`: elemento en posición `n`

### Atributos parciales con CSS Selectors

```js
cy.get('[type*="ubm"]')   // contiene "ubm"
cy.get('[type^="sub"]')   // empieza con "sub"
cy.get('[type$="mit"]')   // termina con "mit"
```

## Resumen

| Selector | Uso |
|---|---|
| `tagname` | Por etiqueta HTML (`div`, `button`, etc.) |
| `#id` | Por ID — único y estable |
| `.class` | Por clase — evitar si es dinámica |
| `[attr="value"]` | Por atributo exacto |
| `[attr^="x"]` | Atributo que empieza con `x` |
| `[attr$="x"]` | Atributo que termina con `x` |
| `[attr*="x"]` | Atributo que contiene `x` |
